# DMOS — showcase

**▶ https://nabvian.github.io/dmos-demo/**

DMOS turns one Wright–Giemsa thin-film blood-smear field into a typed,
unit-carrying, provenance-sealed **structural finding**, and refuses in a
typed, machine-checkable way when the evidence is absent.

This repository holds only a static showcase page: the claim, the nine-stage
pipeline, a refusal explorer, a recorded structural finding, the four
reportability states, the tamper-evident seal, and the failure that was
found and repaired. Every report and message on the page was recorded from
the private DMOS POC v0.1.0 on its synthetic track, with illustrative
configuration values marked as such.

**No DMOS source code is published here.** The source is private and
pre-validation; an open-source release is intended only after clinical
validation.

> Research prototype. Not a medical device, not clinically validated, no
> trained model. Structural descriptors only — no diagnosis. Do not use for
> clinical decisions.
